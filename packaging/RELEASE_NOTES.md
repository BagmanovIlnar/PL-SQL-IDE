## PLSQL IDE 0.0.4

NLS-форматы, строгий ввод параметров по типам, авто-обновление и About-диалог.

### NLS Options (Oracle)

- Preferences → Oracle → NLS Options: форматы даты/времени (User defined / формат Windows / формат сессии Oracle) и символы чисел (десятичный/групповой)
- Настройки не декоративные: при подключении выполняется `ALTER SESSION SET NLS_DATE_FORMAT / NLS_TIME_FORMAT / NLS_NUMERIC_CHARACTERS` (после захвата сессионного NLS — источник «Oracle format» показывает серверные значения), бинды `TO_DATE` и рендер грида следуют тем же маскам
- При не-User defined источниках поля показывают авто-разрешённое значение в read-only рамке — ровно то, что уходит в сессию; вручную маска вводится только в User defined

### Parameters: строгий ввод по типу

- Ввод стал структурным (не посимвольным): в Integer не попасть `6565........` или `6-5`, в Float — `6.......456.456..456.` (ровно один десятичный разделитель, один экспонент)
- Date (Oracle) фильтруется по маске NLS: поле принимает только то, что в неё влезает; семантику (месяц 57) проверяет `TO_DATE` на прогоне
- Float принимает десятичный символ из NLS (`1,5` при запятой), бинд нормализует его в `.` — раньше запятая в поле double precision молча проглатывалась (`1,5` → `15`)
- Значение даты вводится в NLS-формате и биндится как `TO_DATE('...', '<маска>')` (с достройкой `HH24:MI:SS` при времени)

### PostgreSQL → Formats

- Новая страница Preferences: маска ввода даты с radio «Формат ОС» / «Задан пользователем» (в Postgres нет NLS — страница названа честно)
- По умолчанию маска берётся из локали ОС (день-первый → `DD/MM/YYYY`/`DD.MM.YYYY`)
- Введённое конвертируется на клиенте в однозначный ISO-литерал: `25/12/2024` → `'2024-12-25'::date` — сессия сервера не модифицируется
- Поля numeric-параметров PG тоже структурно валидированы, Date — по маске (гибкие поля `5.1.2024`, 2-значные годы по pivot Postgres)

### Авто-обновление и About

- Preferences → Обновление: URL источника (по умолчанию — репозиторий проекта); при старте один тихий запрос к GitHub Releases, при наличии новой версии — модал с предложением, скачивание, подмена бинарника и рестарт
- Help-лента: диалог About (имя приложения, текущая версия, OK)
- Исправление локализации: ключи update/prefs.update/status.copied писались вне секции `strings` и не переводились

### Важно

- Релизные пакеты собраны с фичами по умолчанию (PostgreSQL + Oracle). Instant Client не бандлится — ставится отдельно для подключения к Oracle.
- macOS: приложение не нотаризовано — при первом запуске может понадобиться «Открыть» через контекстное меню.

### Требования

- Rust 1.90+ для сборки из исходников
- Linux: пакеты X11 / Wayland / xkbcommon (см. README)
