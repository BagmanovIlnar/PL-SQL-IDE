## PLSQL IDE 0.0.3

Command console, connection grouping and a batch of usability fixes.

### Command console (SQL*Plus style)

- Окно Command: история команд в диалоге, инлайн-приглашение `SQL>`, кнопка Execute запускает набранную строку (как Enter)
- `/` — повтор последней команды (конвенция SQL*Plus)
- PostgreSQL: скрипт `a; b; c;` выполняется **строго последовательно** — «команда → результат → команда → результат» (работает и из строки `SQL>`, и из вкладки Правки); ошибка одной команды печатается в диалог и очередь продолжается
- Pause ставит очередь на паузу и продолжает с того же места, Stop обрывает остаток очереди
- Вывод NOTICE (Postgres RAISE NOTICE) печатается в диалоге перед таблицей
- Печать значений Postgres: int4/int2/float/bool больше не показываются как `<unprintable>`
- Выделение и копирование всего диалога: Cmd+A / Cmd+C (включая русскую раскладку)
- Строка ввода `SQL>` тянется на всю ширину окна

### Ошибки и диалоги

- Текст ошибки в модалках (включая ошибки подключения) выделяемый: клик/протяжка, Cmd+A / Cmd+C
- В окне Command ошибка не дублируется модалкой — она уже видна в диалоге после `SQL>`

### Вкладки

- Вкладки сгруппированы по подключению: при переключении подключения в поле подключения показываются только вкладки этого подключения; активируется первая его вкладка

### Пакеты

| Платформа | Файлы |
| --- | --- |
| Windows x86_64 | `.exe`, `.zip` |
| Linux x86_64 | `.tar.gz`, `.deb`, `.rpm` |
| macOS Apple Silicon (M) | `.zip` (`.app`), `.dmg` |

### Важно

- Релизные пакеты собраны с фичами по умолчанию (PostgreSQL + Oracle). Instant Client не бандлится — ставится отдельно для подключения к Oracle.
- macOS: приложение не нотаризовано — при первом запуске может понадобиться «Открыть» через контекстное меню.

### Требования

- Rust 1.90+ для сборки из исходников
- Linux: пакеты X11 / Wayland / xkbcommon (см. README)
